# English Word List Source

`english_words.txt` contains the first 3000 pure alphabetic English words
filtered from `aparrish/wordfreq-en-25000`, which is a dump derived from
Robyn Speer's `wordfreq` project.

Source: https://github.com/aparrish/wordfreq-en-25000
